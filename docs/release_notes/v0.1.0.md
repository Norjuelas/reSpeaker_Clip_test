# Release 0.1.0 (pre-release)

## Overview

First release produced by the automated CI: the firmware compile check now
builds both debug + production variants, and pushing a `vX.Y.Z` tag publishes a
GitHub Release (marked **pre-release**) with all 8 artifacts. Firmware-side,
this fixes the close-range WiFi transfer packet loss seen on some phones
(Xiaomi 14) by lowering TX power out of the receiver's saturation zone.

> **Pre-release** — published automatically by CI; promote to a full release
> after verification.

## Changes

### WiFi TX power reduction (receiver-overload fix)

At close range (<30 cm) the phone's WiFi LNA saturated at the old TX power,
corrupting frames at the PHY layer and causing silent, unrecoverable packet
loss during UDP file transfer (most visible on the Xiaomi 14). The phone-side
fix (WifiLock + 200 ms heartbeat) is already in the companion app; this lowers
the device TX power so the received signal stays in the phone's linear range
at >10 cm while still covering 2–3 m for transfer.

- **5 GHz**: 9–13 dBm → **6 dBm** (low/mid/high MCS).
- **2.4 GHz**: 16–21 dBm → **9 dBm** (DSSS / MCS0 / MCS7).
- Test firmware coex band no longer hardcoded to 5 GHz (derives from channel).

### Automated release pipeline

- `.github/workflows/firmware.yml` (push/PR → `main`): compilation check that
  builds **both debug + production** and uploads the artifacts as `vX.Y.Z`
  (tag-style name). Replaced the broken `nrfutil toolchain-manager` chain —
  installs NCS v3.3.0 (Zephyr v4.3) + Zephyr SDK 0.17.0 via `west`; uses
  `zephyr/requirements-base.txt` + `nrf/requirements.txt` to avoid the pip
  `setuptools_scm` backtracking hang.
- `.github/workflows/release.yml` (push tag `vX.Y.Z`): builds debug + production,
  exports the 8 artifacts, and publishes a **pre-release** whose body is this
  file (`docs/release_notes/vX.Y.Z.md`). Release notes must exist before tagging.
